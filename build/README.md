# App Icons

Place the following icon files in this directory before packaging:

- `icon.png` — 512×512 PNG (used for Linux)
- `icon.ico` — Windows icon (256×256 minimum, multi-resolution recommended)
- `icon.icns` — macOS icon (512×512 or 1024×1024)

You can generate all formats from a single high-res PNG using tools like:
- [electron-icon-builder](https://www.npmjs.com/package/electron-icon-builder)
- [png2icons](https://www.npmjs.com/package/png2icons)
